PROJECT 01 · PCB / EMBEDDED

ARVP CAN
Interface

A PC-to-CAN interface PCB developed for the Autonomous Robotic Vehicle Project.

OVERVIEW

Project Problem

As ARVP was creating our electrical system we needed a new board to connect the central computer with the CAN bus. Our previous board was bulky, contained a lot of unnecessary/unused components (I2C, SPI, UART connectors; unused LEDs; etc.) and was hard to read at a quick glance.

Project goal

To solve the outlined problems I planned to make a new board with more no unused ports, larger text, and smaller overall size.

# Hardware Engineering Portfolio

Personal portfolio for electrical/hardware engineering internship applications.

## Deploy with GitHub Pages

1. Create a GitHub repository named `YOUR_USERNAME.github.io`.
2. Upload all files in this folder.
3. Replace `YOUR_USERNAME`, email, LinkedIn, and project links.
4. Add your `resume.pdf` to the repository root.
5. Add project photos to `assets/` and replace the placeholder blocks in the HTML.
6. In GitHub: **Settings → Pages → Deploy from branch → main → / (root)**.
7. Your site will be available at `https://YOUR_USERNAME.github.io`.

## Suggested project documentation

For each hardware project, include:
- Problem / requirements
- Your role
- System architecture
- Schematic
- PCB layout
- Key design decisions
- Manufacturing / assembly
- Testing and debugging
- Results
- GitHub / design files
